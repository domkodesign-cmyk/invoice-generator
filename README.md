# 🧾 Invoice Generator

A lightweight, browser-based invoice generator with PDF export, templates, tax support, and multi-currency options.

👉 Live demo: https://domkodesign-cmyk.github.io/invoice-generator/

---

## 🚀 Features

- Create invoices instantly in browser
- PDF export (jsPDF)
- Multiple templates (Stripe / Minimal / Classic)
- Tax (VAT) support
- Multi-currency support (EUR, USD, GBP, JPY, CNY)
- Local save (no backend required)
- Works on mobile & desktop
- No login required

---

## 🎨 Templates

- Stripe-style SaaS invoice layout
- Minimal clean invoice
- Classic business invoice format

Users can switch templates dynamically.

---

## 📦 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- jsPDF (PDF generation)
- LocalStorage (data persistence)

## 🧠 How it works

1. User enters invoice data
2. Adds items (description, quantity, price)
3. Selects currency and tax
4. Chooses template
5. Generates downloadable PDF
